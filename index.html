🔑 Configuración de IA
📘 ¿Cómo obtener tu API Key?

🔹 Gemini (Google)
Ve a Google AI Studio, inicia sesión, haz clic en "Get API Key". Comienza con AIza.
Modelos gratuitos: gemini-2.5-flash (rápido), gemini-2.5-pro (potente). Límite: 60 solicitudes/minuto.

🔹 Groq
Regístrate en Groq Console, crea una API Key (empieza con gsk_). Ofrece modelos como llama-3.3-70b-versatile (muy rápido). Límite: ~30 req/min.

🔹 Together.ai
Crea cuenta en Together API, genera una clave (sin prefijo fijo). Tiene crédito inicial de $5 y modelos gratuitos como meta-llama/Llama-3.3-70B-Instruct-Turbo-Free.

Las claves se guardan solo en tu dispositivo (localStorage). No se comparten.
